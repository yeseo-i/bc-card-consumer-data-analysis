# BC카드 소비데이터 분석

BC카드 소비데이터를 활용하여 지역 및 업종별 소비 변화를 분석한 프로젝트입니다.

## 분석 내용

### BC카드.ipynb
BC카드 소비데이터를 활용한 기본 분석 및 주요 소비 패턴을 확인했습니다.

### BC카드 시군별.ipynb
시군구 단위로 소비 데이터를 비교하여 지역별 소비 차이를 분석했습니다.

### BC카드 외부데이터.ipynb
외부 데이터를 활용한 추가 분석을 진행했으며, 최종 제출 자료에 활용한 분석 및 그래프를 포함하고 있습니다.

## 사용 도구

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## 데이터

2026년 1월~6월 BC카드 소비데이터를 활용했습니다.
